# FinMaster PRO

Sistema de controle financeiro pessoal desenvolvido em Python.

## Funcionalidades atuais

- Dashboard com tema escuro
- Menu lateral
- Cadastro de receitas
- Banco de dados SQLite
- Cards de saldo, receitas e despesas
- Estrutura organizada em módulos
- Versionamento com Git e GitHub

## Tecnologias usadas

- Python
- SQLite
- Tkinter
- ttkbootstrap
- Git
- GitHub
