# 💰 FinMaster PRO

Sistema de controle financeiro desenvolvido em **Python** para gerenciamento de receitas, despesas e acompanhamento financeiro em tempo real.

## 🚀 Funcionalidades

### ✅ Já implementadas

* Dashboard moderno
* Menu lateral
* Cadastro de receitas
* Banco de dados SQLite
* Cálculo automático de saldo
* Estrutura modular
* Versionamento com Git e GitHub

### 🔄 Em desenvolvimento

* Cadastro de despesas
* Edição de movimentações
* Exclusão de registros
* Atualização automática do dashboard
* Relatórios
* Gráficos financeiros
* Exportação para Excel
* Exportação para PDF
* Sistema de login

## 🛠 Tecnologias

* Python
* SQLite
* Tkinter
* ttkbootstrap
* Git
* GitHub

## ▶️ Como executar

Ative o ambiente virtual:

```bash
source .venv/bin/activate
```

Execute o sistema:

```bash
python dashboard.py
```
